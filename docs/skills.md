## Floor first-run

1. Cowork session with **HubSpot + Gmail + Slack** (same Google for Gmail/Calendar if possible).
2. Paste the **START-HERE batch** prompt (30-day lookback · never-contacted only · up to 50).
3. Approve / edit / skip every line → **“Send approved emails via Gmail.”** (LinkedIn steps wait for HeyReach to be connected.)
4. **Run another batch** later the same day (target **2–3×/day**) — or schedule recurring in Cowork.
5. When replies arrive: **“Check my replies from the Dutch batch and handle them.”**
6. BOOK NOW → Slack you with conversation + 2 slots → you book Ludwig.
7. **“Remember how I write: …”** anytime.

### Do not

- Today-only task pull when the 30-day pool exists · outreach to already-contacted contacts/companies · treat one batch as done forever · LinkedIn send outside HeyReach · Lemlist · send before approve · auto-book Calendar · Slack without conversation · countries outside NL+BE · force LinkedIn scrape on every company every batch.
